# Portafolio de Axel Sanz

Portafolio profesional enfocado en desarrollo .NET, C# y SQL Server.

## Proyecto destacado

**Seguimiento de Ciclos** es una aplicación web desarrollada con ASP.NET Web Forms, .NET Framework 4.8, C# y SQL Server. Centraliza la planificación operativa, importa información desde Excel, presenta indicadores diarios y permite replanificar según capacidad, SLA y días hábiles.

## Ejecutar localmente

El portafolio no requiere instalación ni dependencias. Abrí `index.html` en el navegador o usá la extensión Live Server de Visual Studio Code.
